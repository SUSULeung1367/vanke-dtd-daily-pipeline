# Archive

This directory preserves materials that are not part of the canonical runtime
path.

- `legacy_code/` contains the pre-refactor monolithic Python module.
- `legacy_notebooks/` contains notebooks with duplicated implementation code.
- `legacy_docs/` contains the prior README.
- `analysis/` was moved here unchanged and is intentionally out of scope for
  the maintained pipeline.

Archived material is retained for traceability. New work should use `src/`,
`scripts/`, `notebooks/`, `docs/` and `data/` instead.
